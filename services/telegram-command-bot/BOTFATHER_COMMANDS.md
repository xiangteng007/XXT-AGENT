# BotFather 指令清單

> **用途**: 貼到 BotFather `/setcommands` 設定 Telegram Bot 指令自動完成  
> **最後更新**: 2026-05-04 (v9.2)

## 指令文字（直接貼入 BotFather）

```
start - 顯示總部大廳歡迎訊息
help - 顯示所有可用指令
agents - 切換對話專家代理選單
butler - 呼叫貼身管家
ai - 本地 AI 自由問答
system - GPU / Ollama / Gateway 狀態
analyze - 多智能體投資分析 (加股票代碼)
watch - 追蹤/移除股票 (add/remove + 代碼)
watchlist - 查看監控清單
reg - 法規語義搜尋 (加分類+問題)
info - 查詢客戶、公司與個人資訊
vehicle - 查詢車輛保養資料
eng - 工程進度、BIM 與營造管理
estimator - 工程估算與計價
interior - 室內設計與裝潢建議
scout - 無人機與飛行任務管理
lex - 智財與合約法務諮詢
sage - 數據分析與統計解讀
zora - 企業社會責任與非營利
acc - 稅務/帳務會計問答
loan - 貸款融資諮詢
ins - 保單與保險諮詢
guardian - 風險控管分析
finance - 融資與資本結構
admin - 行政與一般客服問題
social - 社群信號掃描 (stats/top)
cmd - 遠端執行系統指令 (管理員限定)
```

## 設定步驟

1. 開啟 Telegram，搜尋 **@BotFather**
2. 發送 `/setcommands`
3. 選擇你的 Bot
4. 貼上上方指令文字（從 `start` 到 `cmd`）
5. 確認
